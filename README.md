# Cache Recurisve Directory Walk

This mod aims to lower the Skyrim startup times by caching the recursive directory walk done at the start of the game.

Seems to offer startup speed increase of around 10% to 30% for most users.

# Build

Clone the repo and submodules with:
```sh
git clone --recursive git@github.com:LL-Rixu/CRDW.git 
```

To build the project run:
```sh
xmake
```
